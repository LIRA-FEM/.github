# LIRA-FEM — structural model with FE design checks

LIRA-FEM keeps one named board on the desk: the live members, the design check in front of you, and a short note the next engineer can read. Extra office models wait for their own title.

## Session Card

| Slice | What you do in LIRA-FEM | What remains |
|-------|------------------------|--------------|
| Arrival | Open LIRA-FEM and name today's office model | A titled structural model |
| Focus | Keep only live members on the LIRA-FEM board | A short check list |
| Check | Read LIRA-FEM design checks before a large FE change | A confirmed office model |
| Handoff | Mark finished checks inside LIRA-FEM | A note for the next engineer |

## How LIRA-FEM Sits

LIRA-FEM does not replace the second sketch, the unlabeled member dump, or the separate check sheet you already keep. It sits beside them as a named office model for one job: which structural model is live, which FE analysis still matches the design checks, and what the next engineer should read.

## Traffic Light

| Signal | On the LIRA-FEM board | What you do |
|--------|----------------------|-------------|
| Green | Named office model, short live member list | Continue the same FE analysis |
| Amber | Two buildings mixed on one structural model | Split the members before a large change |
| Red | No title, no note, checks on a second sketch | Stop and name the office model first |
| Clear | Handoff written, live checks few | Close LIRA-FEM and leave the office model |

## Open Order

1. Open the last LIRA-FEM office model, not a new empty structural model.
2. Read the design checks and the last handoff.
3. Finish one visible FE analysis pass inside LIRA-FEM.
4. Write what changed, then close with fewer second sketches than you found.
5. If the model feels crowded, drop anything that belongs to a different LIRA-FEM building.

## After a Week

A week in LIRA-FEM is not a larger pile of second sketches. It is the same title, a shorter live member list, and a note that still makes sense before the next design check. Take finished checks off the live set so the next visit starts on the office model that is still open.

## Sign-off

- [ ] The LIRA-FEM workspace name is short enough to scan
- [ ] Only live members sit on the structural model
- [ ] A second engineer can read the check handoff
- [ ] The last LIRA-FEM office model still opens after a restart

## Field Note

LIRA-FEM is easier to trust when the office model stays smaller than the second-sketch pile it came from. Name the structural model, keep the live members, finish one visible design check, and write what changed.
